## 🌟 What is Primo?

Primo is an open-source humanoid robot that you can **3D print and build yourself**! Powered by 30 high-performance RobStride actuators and an NVIDIA Jetson Thor computer brain, Primo is designed for anyone interested in robotics, artificial intelligence, and the future of human-machine interaction.

Whether you're a hobbyist, student, teacher, or robotics enthusiast, Primo gives you the opportunity to own and operate a cutting-edge bipedal robot. Because it's currently **in the design phase**, you're getting in on the ground floor of an exciting open-hardware project!

---

## 🎯 Key Features

| Feature | Description |
|---------|-------------|
| 🦿 **True Bipedal Movement** | Walks on two legs using advanced quasi-direct-drive actuators |
| 🖨️ **Fully 3D Printable** | All structural parts can be printed on a standard consumer 3D printer |
| 🧠 **Jetson Thor Brain** | NVIDIA's powerful AI computing platform for real-time decision making |
| 🔧 **30 RobStride Actuators** | High-torque, precise motors for smooth and powerful movement |
| 📐 **Onshape CAD Files** | Complete 3D model available for modification and customization |
| 🤖 **Reinforcement Learning Ready** | Works with NVIDIA Isaac Lab and Isaac Sim for AI training |
| 🌍 **Open Source & Open Hardware** | Everything is free to use, modify, and learn from |

## 🔨 Assembly Process

While Primo is still in the design phase, here's what you can expect when the final files are released:

1. **Print all parts** - Approximately 20-30 hours of printing time
2. **Prepare electronics** - Wire up the Jetson Thor and connect actuators
3. **Assemble the body** - Follow the step-by-step illustrated guide
4. **Load the software** - Flash the provided code to the Jetson
5. **Calibration** - A guided setup process aligns all 30 actuators
